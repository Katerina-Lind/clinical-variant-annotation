# Clinical variant annotation — prototype v0.1
Research-only SNV/indel annotation, not a validated diagnostic pipeline.

## Requirements
Nextflow DSL2, Docker for local execution or a configured Seqera AWS Batch environment. Verify both image tags before running; override image parameters if necessary. VEP release 115 and matching offline Ensembl human GRCh38 cache directory (containing homo_sapiens/115_GRCh38), exact GATK reference FASTA and .fai, GRCh38 ClinVar bgzip VCF and tabix index. Check source reference provenance and contig dictionaries before launch. Pin database dates and checksums separately. The supplied reference is a candidate from TIDDIT, not yet verified against GATK. ClinVar requires CLNSIG, CLNDN, CLNREVSTAT and compatible chromosome naming. Verify VEP container includes tabix. Cache and reference must be accessible to container; large cache staging via Fusion requires testing.

## Run
Copy params.example.json to params.json; replace resource placeholders. For a local test replace S3 paths with local files, set outdir to a local directory and use `nextflow run main.nf -profile local -params-file params.json -resume`. For Seqera use the workspace AWS Batch environment and params file values; standalone AWS Batch requires queue/work directory and appropriate IAM/Fusion configuration. Do not launch a full genome before a region smoke test (subset raw VCF using bcftools view -r chrX:54455000-54456000 -Oz, index, update inputs).

## Design notes
Split multiallelic sites before extracting child; overlapping alternative alleles are represented as missing rather than falsely reference. Keep original record tag and original trio source; allele-specific AD after splitting does not retain other ALT depths. Inheritance TSV contains all normalized trio records (including parental-only variants), no header; column schema in QC. Join by CHROM/POS/REF/ALT and review original multiallelic records. No automatic de novo, X-linked or pathogenicity calls. No frequency or FILTER screening in master; PASS subset excludes unfiltered sites. SNVs/indels/MNVs only. Site-level GATK INFO and FILTER may describe original joint cohort, not individual. No-call sites are not output; not a negative-test or callable-region report. Review chromosome X ploidy/PAR independently. VEP CSQ header checks and genotype/allele equality are smoke QC, not clinical validation. Duplicate normalized keys and annotation coverage by resource require further validation. VEP plugins are not configured; vep_extra accepts trusted CLI arguments only and plugin resources need explicit staging/mounts. Extended features are planned, not implemented. No runtime tests were possible in authoring environment.
